# SPEC-004: Scene List & Editor

## Goal
Table/list of all scenes in a project with the ability to edit them.

## Requirements
- List all scenes belonging to a selected project.
- Show scene number, scripture reference, location, day/night, and short action summary.
- Edit any scene.
- Delete any scene.
- Reorder or renumber scenes with simple direct number editing.
- Show a clear empty state when a project has no scenes.

## Acceptance Criteria
- Scenes load correctly for the selected project.
- Edit and delete persist.
- List updates immediately after changes.
- Empty state is clear.

## Out of Scope
- Call sheets
- Calendar / shoot days
- Budget
- Any other SPEC
