# APEX STARK MODE

STARK Mode is the operator-facing orchestration layer: research, strategy construction, evidence tracking, risk analysis, decision records, tool permissions, and production workflows can be composed into one command surface.

## Operating principle

Observe → Research → Model → Stress-test → Execute only with explicit authorization → Audit.

For financial workflows, Apex should separate factual market data from assumptions, model multiple scenarios, expose uncertainty and downside, and require explicit human authorization before placing orders or moving funds. No strategy is guaranteed to pay out.

STARK Mode is an architecture metaphor, not an autonomous authority. The operator remains in control.
