# Bible Film Production

KernelVision is a general cinematic production studio, not a Korn-only video generator.

Supported production domains:
- `bible` — Scripture-based films, episodes, shorts, documentaries, explainers, and other Bible media.
- `korn` — GardenApex / Jesus Freaks productions.
- `original` — original non-Bible, non-Garden productions.

## Bible mode

Bible productions use Scripture/source provenance as their truth boundary. They can use Scripture research, historical/context research, character and scene planning, original cinematic visualization, Kernelodies audio capabilities, deterministic render QC, durable production-job handoffs, and release packaging.

Production jobs must use the active sovereign persistence path. Do not introduce PostgreSQL dependencies or treat a database row as proof of completed media. The repository still contains legacy storage paths; current compliance is not established until active write paths and recovery tests are verified.

Bible mode does not require GardenApex references.

## Korn mode

Korn productions use the verified GardenApex graph/package and its environmental rules. Unverified Garden references are rejected before production handoff.

## Studio rule

**KernelVision can make Bible movies and videos as a first-class production domain. Korn content is one domain, not the definition of the Studio.**
