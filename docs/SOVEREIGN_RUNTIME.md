# Apex Sovereign Runtime

Apex can be deployed as a self-hosted, local-first system with explicit network controls.

- Network egress is denied unless enabled.
- Optional hostname allowlisting narrows remote access.
- Local authentication/session primitives avoid mandatory third-party identity.
- AES-256-GCM helpers support encrypted state at the application boundary.
- Egress attempts can be audited.

A strong private deployment can run Apex with local storage and local model servers, expose no public port, and keep backups under operator control.

These controls are for legitimate privacy, ownership, resilience, and reduced unnecessary data exposure. They do not make a system invisible or exempt it from applicable law, access rules, or provider safeguards.
