# Apex Universe Model

Apex treats creative continuity as a spatial-temporal graph.

**Universe → Galaxy → Region → Stellar System → World → Location → Scene → Shot → Asset**

Every layer can carry:
- provenance
- continuity constraints
- entities and relationships
- timeline membership
- agent ownership
- asset lineage
- production status

The model is intentionally provider-neutral. AI providers generate outputs; Apex owns state, provenance, continuity, orchestration, evaluation, and lineage.
