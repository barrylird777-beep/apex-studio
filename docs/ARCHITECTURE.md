# Apex Bible Story Studio Architecture

Bible source → story event → scene → shot → asset/audio → timeline → render → release

Core state includes biblical sources, story provenance, research, characters, world state, continuity, scenes, timelines, visual realism, assets, production jobs, renders, and releases.

Creative routes:
- Oracle: cinematic script generation.
- Forge: image/visual generation.
- Bard: narration/audio generation.

Modern copyrighted translations should not be bundled without authorization. Store source metadata, edition/translation, locator, license, and provenance separately from imported text.

The codebase excludes adult/intimacy, companion, Stark Mode, and unrelated universe infrastructure.
