## APEX RULES
1. No tool gets direct authority to merge production code.
2. No SQLite for the durable worker foundation.
3. No speculative Redis/queue/infrastructure.
4. Every agent must work from actual repository state.
5. Every mutation requires diff + focused tests + evidence.
6. Builders do not self-certify.
7. Adversarial agents attempt to break claimed fixes.
8. Integration validates cross-workstream compatibility.
9. King Cob remains final inspector.
10. Never claim an external agent ran unless repository/tool evidence proves it.

## MOBILE-FIRST EXECUTION
Because the owner operates from iPhone, prioritize browser/cloud/GitHub-native workflows and agents that can run remotely. Do not make local-terminal setup a prerequisite for progress.

Auth/security -> durable queue -> worker fleet -> AI mesh -> media -> API contracts -> CI/release -> chaos/load -> final integration.
